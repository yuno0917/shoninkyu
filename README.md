# 初任給の手取り計算機

初任給（月給）・通勤手当・働く都道府県・入社する年から、新卒1年目の4月、5月から、12月の年末調整、2年目6月からの住民税まで、月ごとの手取りを計算する Web ツールです。公開先は https://yuno-lab.com/shoninkyu/ です。

前提：協会けんぽ・独身・扶養なし・4月入社・当月払い（社会保険料は翌月の給料から）・残業代とボーナスなし。

- 健康保険：協会けんぽ 令和8年度の都道府県の料率＋子ども・子育て支援金0.23%を合わせた率で、標準報酬月額（月給＋通勤手当）の半分。50銭以下切り捨て・50銭超切り上げ
- 厚生年金：18.3%の半分（標準報酬月額 88,000〜650,000円）
- 雇用保険：通勤手当を含む総支給額 × 5/1000（令和8年度）
- 所得税：国税庁「電子計算機等を使用して源泉徴収税額を計算する方法」（令和8年分・令和9年分）。月額表とは数十円違うことがある
- 年末調整：令和8・9年分（給与所得控除の最低74万円、基礎控除104万円）、102.1%・100円未満切り捨て
- 住民税：令和9・10年度（基礎控除43万円、調整控除、所得割10%、均等割4,000円＋森林環境税1,000円）。端数は6月の分
- まだ公表されていない年度（2027年度からの保険料率、2028年分の源泉徴収）は、最後に公表された数字で計算し、画面に注記を出す

## 毎年の更新（3〜4月）

1. `js/tk-data.js` の料率（協会けんぽの47都道府県、支援金率、雇用保険料率）と源泉徴収の数字を新しい年度にする。`knownYear` も進める
2. 入社する年の選択肢（`index.html` の `name="year"`）と `normalizeInput` の年を1年進める
3. `tests.html` の期待値を、公式の資料で手計算した値に直し、テストがすべて通ることを確認する
4. `index.html` の早見表・都道府県の表・例の表を、同じ計算で作り直す（`tests.html` の早見表と都道府県のテストも直す）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 入力フォーム・結果・例・早見表・都道府県の表・よくある質問・計算のしかた・参考資料・免責 |
| `tests.html` | ロジックのテスト（ブラウザで開くと結果を表示） |
| `js/tk-data.js` | 料率と表（公式の資料の数字） |
| `js/tk-calc.js` | 計算（DOM に触れない）と入力のチェック |
| `js/app.js` | フォーム・描画・保存・共有リンク |
| `css/style.css` | ほかのツールと共通（bench-program のものをコピー） |
